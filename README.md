# 🚀 Production DevOps Platform on AWS EKS

A production-grade DevOps platform built on **AWS** using **Amazon EKS**, **Terraform**, **GitHub Actions**, **Helm**, and **Prometheus/Grafana**.

The goal of this project is to demonstrate the complete software delivery lifecycle, from infrastructure provisioning to application deployment, monitoring, and security, following production best practices.

---

# 📌 Project Objectives

- Provision AWS infrastructure using Terraform.
- Build and manage an Amazon EKS cluster.
- Containerize a Java application using Docker.
- Store container images in Amazon ECR.
- Automate CI/CD with GitHub Actions.
- Deploy applications using Helm.
- Monitor workloads with Prometheus and Grafana.
- Apply DevSecOps best practices.
